# Biomechanics_MAC447

## Scripts

### knee_flexion_individual_trial.py
This script processes knee flexion data for individual walking trials and generates the corresponding knee flexion plots and summary outputs.

### process_knee_pig_walking.py
This script processes the knee walking data from the pig dataset, preparing the movement data for analysis and producing the related knee angle outputs.

### Symmetry_Index_indivdiual_trial.py
This script computes the symmetry index for individual trials, allowing comparison of left/right or trial-to-trial symmetry in knee movement.

## Results and Data

The results generated by these scripts are stored in the `results` folder.

The data used by these scripts is located in `Part_B_Data`.
